# Stella & Dad Arcade

Seven browser games in plain HTML. No build step, no installing, no accounts.
Double-click `index.html` and it works.

Every game has a **♪ button in the top bar** that turns sound on and off. The setting
sticks across all seven games and is remembered next time you open it. Nothing is
downloaded to make the sounds — every beep, pop and thud is generated by maths in the page.

## The games

| Game | What it is | The twist |
|---|---|---|
| **Soccer Duel** | 2-player physics soccer | Hold DASH to charge, release to blast. Same screen, vs computer, or phone-to-phone |
| **Block Drop** | Tetris variant | Every 10 lines earns a Firebomb that blows a 3x3 hole |
| **Viper** | Snake | Golden ball worth triple, but it disappears if you're slow |
| **Sudoku** | Sudoku | Puzzles generated fresh every time, guaranteed one solution |
| **Block Blast** | Shape-fitting puzzle | Fill a row or column to blast it; combos stack |
| **Bubble Pop** | Bubble shooter | Match three to pop, and anything left hanging falls |
| **Relic Hunter** | Side-view adventure | A jungle temple, four traps, a rival, and a narrator who is not on your side |

## Controls

**Soccer Duel**
- Orange player: `W A S D` to move, `Left Shift` or `Space` to dash
- Blue player: arrow keys to move, `Enter` or `Right Shift` to dash
- On a phone/tablet: thumbsticks and DASH buttons on screen

**Block Drop** — arrows to move, `Up`/`X` rotate, `Space` hard drop, `C` hold, `P` pause.
On a phone: buttons underneath, or swipe on the board.

**Viper** — arrows or `WASD`. On a phone: swipe or use the D-pad.

**Sudoku** — click a square, type 1-9. `N` toggles pencil notes.

**Block Blast** — drag a shape onto the board, or tap the shape then tap where it goes.

**Bubble Pop** — aim with the mouse or your finger, let go to fire. Arrow keys and `Space` also work.

**Relic Hunter** — arrows or `WASD` to walk, `Up`/`Space` to jump, `E` to use, `Q` to look.
On a phone: the buttons underneath. Tap an item in your satchel to select it, then USE it on something.
It saves as you go, so you can close the tab and pick it up later.

## Playing phone-to-phone

1. Both phones open the **hosted** version of the site (this needs to be online, not a downloaded file).
2. One person taps **Host a game** and reads out the 4-character code.
3. The other taps **Join a game** and types it in.

The host's phone runs the game and sends positions to the other phone many times a second.
It uses PeerJS, which connects the two phones directly to each other.

## Putting it on GitHub Pages

1. Make a new repository on github.com — call it something like `stella-arcade`. Make it **Public**.
2. Upload every file and folder here, keeping the structure:
   ```
   index.html
   README.md
   games/
     soccer.html
     blockdrop.html
     viper.html
     sudoku.html
     blockblast.html
     bubblepop.html
     relic.html
   vendor/
     peerjs.min.js
   ```
3. In the repo go to **Settings → Pages**.
4. Under "Build and deployment", set Source to **Deploy from a branch**, branch **main**, folder **/ (root)**. Save.
5. Wait a minute, then your arcade is live at:
   `https://YOUR-USERNAME.github.io/stella-arcade/`

That link works on any phone, and it's what you need for phone-to-phone soccer.

## Changing things (this is the fun part)

Open any game file in a text editor. Near the top of each one there's a block marked:

```
/* ---------- TWEAK ME ---------- */
```

Those are the numbers that decide how the game feels. Some good first experiments:

- `soccer.html` → `DASH_POWER` — turn it up to 40 and see what happens
- `soccer.html` → `WIN_SCORE` — make it first to 3 for a quick game
- `blockdrop.html` → `START_SPEED` — lower number = faster falling
- `blockdrop.html` → `LINES_PER_FIREBOMB` — set it to 3 for chaos
- `viper.html` → `GRID` — 30 makes a much bigger board
- `blockblast.html` → `N` — a 10×10 board changes the whole game
- `bubblepop.html` → `PALETTE` — take a colour out to make it easier, add one to make it brutal
- `bubblepop.html` → `SHOTS_PER_DROP` — lower means the wall comes down faster
- `relic.html` → `BOULDER_SPEED` — the boulder chase lives or dies on this number
- `relic.html` → `CODE` — the stone-door combination; change it and the tablet clue lies to you
- `relic.html` → the `WORLD` block is every room in the game. Copy a room, change the numbers, you've made a level.
- Any game → the `--accent` colour at the very top of the `<style>` block

Change one thing at a time, save, reload the page. If it breaks, undo that one change.
